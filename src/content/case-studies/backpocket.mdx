## The 6 AM brief

Search only helps if you remember to look. So every morning, the agent reads my calendar and inbox and sends one message with what matters today.

<BriefFlow />

## How it works

Every message runs through the same pipeline. Claude handles each judgment through its own tool with a strict schema, and every answer is validated before it's used.

<AgentArchitecture />

<Cards
  items={[
    { title: "Eight focused tools", body: "Routing, cards, answers, lists, screenshot checks, prep picks and email matching each get their own Claude tool." },
    { title: "Checks its own output", body: "Every model response is validated. If it fails, the agent retries once, then replies with a friendly error." },
    { title: "Safe by default", body: "Signed requests only, an allowlist of numbers, no repeat saves when Meta retries, and each person's data kept separate." },
  ]}

## What broke

I used it on my own saves from day one. Every fix came from something going wrong.

<LessonCards
