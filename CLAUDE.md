## Content rules
- Never invent metrics, titles, dates, or outcomes. If a fact is missing, write MISSING CONTENT 
- If the resume and any other source disagree, use the resume and flag it.
- Never publish internal company data beyond what's on the resume.
- No em dashes. No AI-sounding phrases ("leveraged", "spearheaded", "passionate about", "caught my eye", "delve").
- Tone: warm, concise, a little playful. Write like a person, not a LinkedIn post.

## Design rules
- Keep my current palette, fonts, and design elements (see /reference/design-tokens.md once created).
- Take layout and interaction patterns from the inspiration site. Never copy its text or code.
- Mobile-first. Respect prefers-reduced-motion. Animations should feel fun but purposeful.
- Use placeholder images for now. Store all images in /public/images with fixed filenames and list each one (filename, where it appears, ideal size) in /reference/image-list.md.
